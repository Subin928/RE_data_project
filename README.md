# 프로젝트 정리
-----
## 프로젝트 제목
* 장마철 태양광 발전 공백 분석 및 서울 지역 ESS 최소 필요 용량 산정
-----
1. 프로젝트 분석 및 목적
-----
장마철(6\~7월)기간 동안 태양광 발전량은 일사량 증가로 30\~70% 증가하지만, 높은 습도·구름·폭우 등으로 인해 일시적 공백이 발생한다.
본 프로젝트는 2020~2025년 사이 서울 지역의 과거 기상 데이터와 발전량 데이터를 분석하여 발전 공백 시 필요한 ESS(에너지저장장치) 최소 용량을 정량적으로 산정하고, 최적의 ESS 용량 운용 방안을 제시하는 것을 목적으로 한다.
------
2. 프로젝트 목표
* 2020~2025년 사이 서울 지역 기상 데이터 기반 장마철 태양광 발전량 분석
* 강수량과 발전량의 상관관계 규명 및 예측 모델 구축
* 최악 시나리오 대비 ESS 필요 용량 산정
------
3. 데이터 구성
* 서울시 장마철·비장마철 강수량 데이터
* 서울시 장마철·비장마철 일사량 데이터
* 서울시 자치구별 태양광 발전소 설치현황 데이터
-----
4. 결과 요약
서울시 태양광 발전은 자치구별 설치 규모와 특성 차이로 인해 ESS필요 용량에도 차이가 났다
비장마철에는 월 평균 약 400kWh 수준의 ESS가 필요했으며, 장마철 최악의 경우 약 78kWh의
전력 부족이 발생해 추가 보완이 필요한 것으로 확인되었다.
이는 장마철 발전 변동성이 ESS 수요를 증가시키는 요인임을 보여주고 있다.
따라서 도심 지역은 소규모 태양광 확대와 ESS 연계 운영이, 외곽 지역은 분산형 태양광과 ESS를 결합한 전략이 필요하다.
-------
5. 본 프로젝트의 한계
* 본 프로젝트의 정책 설계보다는 정책 방향성을 데이터로 뒷받팀하는 데 목적이라 구체적인 정책 수단은
후속 연구나 실제 행정단계에서 보완이 필요하다.
* 본 데이터 분석에서 자치구별 설치 분포와 발전 특성이 다르게 나타났기 때문에 동일한 정책을 일괄 적용하기 보다 지역
특성을 고려한 전략이 더 효율적일 수 있음을 시사한다.
-------
